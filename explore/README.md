# 草商探索趣

「今天，換你當草商新生！」國立草屯商工的 3D 校園探索遊戲。帶著探索護照，點校園建築認識各科、完成小任務收集金幣，最後領取寫著自己興趣方向的「探索證書」。

- 校園配置依「115 學年度全校平面圖」（約 10 像素 = 1 單位，寫在 `PLAN`）：上排誠工樓、誠教樓、誠治樓與宿舍，中軸為中央大道、誠愛樓（圖書館）、中央草坪與水池，下排藝升樓、誠學樓，西側潔采樓、球場與運動場；平面圖上正校門在右下角，轉成實際方位後在西南角。
- 誠工樓、誠教樓、藝升樓、誠學樓做成三合院：兩翼山牆屋頂與白色封簷、洗石子框架配粉紅磚、綠欄杆迴廊、菱形窗、後棟，正面是兩層門廊與青綠色樓名牌。
- 資料處理科卡片與「看資處科完整介紹」內容取自科內簡報（2026-3-10），照片在 `media/data/`，資料在 `DEPT_INTRO`。
- 商業經營科卡片與「看商經科完整介紹」內容取自科內簡報「商業經營科巡禮」，照簡報的 LEVEL UP 遊戲風格做成黃／青／洋紅配黑框的版面：師資、三大專業教室（全南投唯一門市服務丙級檢定合格場地）、高一到高三課程藍圖與技能樹、證照成就牆、校外競賽／參訪／實習照片、升學與就業進路、村長的信。照片在 `media/biz/`，資料在 `DEPT_INTRO.biz`。
- 13 個探索點（9 個科別＋誠愛樓、921 重建紀念亭、正校門正對面的萊爾富、校門右手邊的南台灣土魠魚羹），各有一個一分鐘內完成的小任務，完成顯示「你認識了這個科別！」並得到一枚金幣。
- 正校門：伸縮門、警衛室在門內右側，「國立草屯商工」校名牆與賀榜在門口右側；進門右手邊是「師道」書法碑文牆與橢圓荷花池，旁邊是校長宿舍；誠愛樓（圖書館）前有藍色棚頂的司令台。
- 方位依 Google 地圖校正：平面圖整體順時針轉 90°（程式裡 `CAMP` 群組，平面圖座標 (x,z) → 世界 (−z,x)）。校園南北向，運動場在西北、潔采樓在東北、中央草坪南北向，正校門在西南角。
- 周邊交通：北側緊貼中投快速道路（台63，高架、雙向車流），中投北側有撐竿跳場（太陽能板屋頂的長型場館＋綠網沙坑）；西側台14線、往東南的芬草路二段、東邊新庄二路與新庄國小；台14線以西是民房。
- 門口店家：萊爾富在芬草路二段對面，南台灣土魠魚羹在出校門往右、店面朝台14線，旁邊還有沙軒茶坊、弘爺漢堡，都做成放在底座上的微型模型。
- 走動的角色是學生公仔：白色藍袖運動服＋校徽、藍短褲或紅線長褲、眼鏡、白色底座，停下來時會揮手。
- 撐竿跳場（中投北側）：太陽能屋頂的長型訓練館＋綠色圍網的沙坑、海綿墊與橫桿，可從北側校門經快速道路下方走過去。
- 正校門進入右手邊（南側圍牆）是「師道」：洗石子牆、深色瓦片牆帽、粉紅腰帶、「師」「道」大字與整排書法碑文，前方是種滿紅色仙丹的蓮花水池花台，旁邊是校長宿舍。
- 誠愛樓（圖書館）前有藍色雨遮的司令台。
- 民房不加標示；所有民房都會避開道路（`freeLot()` 檢查與道路、校園、店家的距離）。
- 進度存在瀏覽器的 localStorage（`caotun-explore-v1`）。
- 科別、授課重點、證照、小任務都寫在 `index.html` 頂端的 `Q`／`GAMES`；路徑網路在 `N`／`EDGES`。

## 舊版說明：Discord 動態（仍然沿用）

國立草屯高級商工職業學校的 3D 互動特色島。架構參考〈虎尾科大資工系特色島〉（單一 `index.html`、Three.js 0.160、importmap、不需建置），資料換成草屯商工的科別內容，並由課程 TA Bot 提供 Discord 即時動態。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 整個網站。頂端的 `DATA` 物件放學校與各科資料（授課重點、證照、榮譽、資料來源） |
| `api/feed.js` | Vercel 函式：TA Bot `POST` 快照、網頁 `GET` 讀取，存在 Upstash Redis |

## 島嶼

- 中心：草商廣場（校本部：願景、校訓、學生圖像、沿革）
- 內圈：機械科、配管科、資料處理科、會計事務科、商業經營科、應用英語科
- 外圈：證照殿堂、Discord 廣場（TA Bot 塔）、進修部、綜合職能科、體育班、電腦繪圖科（實用技能學程）

每座島的島民人數 = 該科頻道近 15 分鐘發言人數；有新訊息時 TA Bot 塔會飛出一封信送到該科小島，島民頭上冒出對話框；#證照捷報 有人回報通過時，該科與證照殿堂會放彩帶。進行中的 Discord 活動會在島上放氣球並在名牌上標示。

## 部署

1. 把整個資料夾推上 GitHub，在 Vercel 匯入。
2. Vercel → Settings → Environment Variables：
   - `UPSTASH_REDIS_REST_URL`、`UPSTASH_REDIS_REST_TOKEN`（或 Marketplace 自動注入的 `KV_REST_API_URL`／`KV_REST_API_TOKEN`）
   - `FEED_TOKEN`：自訂一串長密碼，TA Bot 推送時要帶
3. TA Bot 端：`pip install aiohttp`，把 `bot/island_feed.py` 放進專案，啟動時 `await bot.load_extension("island_feed")`，並設定
   - `ISLAND_FEED_URL=https://你的網域/api/feed`
   - `ISLAND_FEED_TOKEN=`（同 `FEED_TOKEN`）
4. 依伺服器實際頻道名稱修改 `CHANNEL_DEPT`。

網頁每 20 秒讀一次 `api/feed`；讀不到（尚未部署、Bot 離線）時會自動播放示範資料，左上角標示「示範資料」，接上後變成紅點 LIVE。

## #證照捷報 的寫法

`機械科 電腦數值控制車床 丙級`、`會計科 會計事務－人工記帳 丙級`。
證照名稱要和 `index.html` 裡 `DATA.islands[].certs` 一致，進度條才會對上。Bot 的證照計數存在記憶體，重啟會歸零；要長期保存可改寫成存檔或資料庫。

## 隱私

只傳暱稱與 60 字內的訊息摘要，網址會被移除；把 `ANONYMIZE = True` 會改顯示「機械科同學」。不要傳學號、真實姓名或私訊內容。

## 本機預覽

`npx serve .` 即可看示範模式；要測 API 用 `vercel dev`。

## 完成名次（Google Apps Script）

集滿 13 枚金幣後，點客服中鼎文會顯示「你是第 N 名完成探索的新生」。程式在 `apps-script/Code.gs`，不需要試算表，**不記名字、不留名單**，只記目前完成人數。前 50 名的畫面會出現兌換憑證，第 51 名起顯示「謝謝探索，獎品已經兌換完畢」。同一個瀏覽器重開或重整，名次不變。

### 設定步驟

1. 用電腦開 <https://script.google.com>，登入要管理這個計數的 Google 帳號，按左上「新專案」。
2. 左上「未命名的專案」改名為「草商探索趣 名次」。
3. 編輯器裡的 `Code.gs` 全選刪掉，貼上 `apps-script/Code.gs` 全部內容，按磁碟片圖示儲存。
4. 上方函式選單選 `showCount` → 按「執行」→「審查權限」→ 選帳號 →（出現「Google 尚未驗證這個應用程式」時）「進階」→「前往 草商探索趣 名次（不安全）」→「允許」。下方執行紀錄出現「目前完成人數：0 人」就是成功。
5. 右上「部署」→「新增部署作業」→ 左邊齒輪選「網頁應用程式」→ 說明填「名次」、執行身分選「我」、誰可以存取選「所有人」→「部署」→ 複製「網頁應用程式網址」（結尾是 `/exec`）。
   - 學校帳號如果只有「（學校網域）中的所有使用者」、沒有「所有人」，代表學校限制對外分享，一般訪客會連不上。請改用個人 Gmail 重做，或請資訊組開放。
6. 測試：瀏覽器開這個網址，看到 `{"ok":true,"finished":0,"limit":50,"left":50}`。再開 `網址?action=rank&cid=test-teacher-01&coins=13`，看到 `"rank":1`；同一個網址再開一次還是 `1`，代表不會重複計算。
7. 歸零：回編輯器，函式選 `resetCount` →「執行」。正式開放前一定要做，不然剛剛的測試會占掉第 1 名。
8. 把 `/exec` 網址填進 `index.html` 開頭的 `<meta name="caotun-rank-api" content="這裡">`，再建置發布。

### 平常管理

- 看完成人數：開 `/exec` 網址看 `finished`，或在編輯器執行 `showCount`。
- 重新開一輪：執行 `resetCount`。
- 改小禮物名額：改 `Code.gs` 的 `PRIZE_LIMIT`；網頁的 `PRIZE_LIMIT` 也要改成一樣（`index.html` 搜尋 `const PRIZE_LIMIT`）。
- 改完程式要「部署 → 管理部署作業 → 鉛筆 → 版本選『新版本』→ 部署」才會生效，網址不變。只按儲存不會更新線上版。

### 限制

- 名次跟著瀏覽器走：換手機、換瀏覽器或清除瀏覽器資料，會被當成新的一位。
- 任何人拿到網址都能自己加人數，這是方便管理的計數，不是防作弊機制。換小禮物時請中鼎文看學生畫面上的名次與時間。
- 每個瀏覽器在指令碼屬性存約 20 個字元，上限約 500KB，可記上萬人。
- 沒填網址或連不到 Google 時，畫面照常顯示憑證，註明名次以中鼎文現場確認為準。
